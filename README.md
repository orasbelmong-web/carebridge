# CareBridge AI

공공 빅데이터와 일상 라이프로그 연동 기반 **지능형 모바일 홈 헬스케어 플랫폼** 시연 웹사이트

2026 빅데이터 활용 현장문제 해결 경진대회 제출작 · 팀 Data-Care Innovators · 김기윤

## 주요 기능

- **의료 공백 위험 지수(HGI)**: 상위 10개 지역 랭킹, 슬라이더로 공식을 직접 계산해 보는 시뮬레이터
- **노령화 지수**: 전남 261.74 · 경북 259.16 · 강원 256.69 (통계청 인구주택총조사 분석)
- **Zero-Touch UX**: 일상 측정 → 자동 페어링 → 클라우드 동기화 3단계 시연
- **지능형 예방 메커니즘 체험**: 혈압 스트림에서 위험 임계점을 넘으면 환자·보건소·보호자에게 삼각 알림 (Care Connect)
- **시스템 아키텍처**: 수집 → 전처리 → AI 분석 → 실행 4단계
- **Paradigm Shift**: 오프라인 병원 중심 vs CareBridge AI 중심 비교표
- **수익 모델과 파급 효과**: B2G / B2B / B2C 구조, 재정·MIS·사회적 포용성

## 로컬에서 실행

`index.html` 파일을 내려받아 브라우저로 열면 됩니다. 외부 라이브러리나 서버가 필요 없어 인터넷 없이도 동작합니다.

## 유의 사항

- 혈압 시뮬레이터는 **데모용 가상 데이터**이며 실제 XGBoost/LSTM 모델이 아닙니다.
- HGI 시뮬레이터의 기준값은 체험을 위한 **가정치**입니다. HGI 지역 순위는 발표 자료의 산출 결과를 따랐습니다.
- 본 사이트는 의료 진단 도구가 아닙니다.

## 기술

단일 HTML 파일 (HTML + CSS + JavaScript), 다크 모드 자동 지원
