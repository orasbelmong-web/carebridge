# CareBridge AI

공공 빅데이터와 일상 라이프로그 연동 기반 지능형 모바일 홈 헬스케어 플랫폼 소개 사이트입니다.
2026 빅데이터 활용 현장문제 해결 경진대회 제출작 · Team Data-Care Innovators

**사이트:** https://orasbelmong-web.github.io/carebridge/

## 한눈에 보기

- 2024년 만성질환 환자 13,416,324명, 이 중 65세 이상 6,119,357명(45.6%)
- 85세 이상 환자는 2020년 대비 +43.0% 증가
- 전국 지역보건의료기관 3,607개소 (보건소·보건의료원 263곳, 보건진료소 1,894곳)
- 2030년 65세 이상 환자 약 806만 명 전망 (2024년 대비 +32%)

## 사이트 구성

문제 · 경쟁 비교 · 차별점 · 지역보건기관 분포(시도·시군구) · HGI 계산기 · 환자 구조(고령화) · 환자 수 예측 모델 · Zero-Touch 시연(위험 징후 주입, 음성 가이드, 자동 시연) · 역할별 화면(환자·보호자·보건소) · 아키텍처 · 패러다임 · 수익 모델 · 파급 효과(절감 효과 계산기) · 출처

## 예측 모델

연령 22구간 × 성별 × 보험유형(건강보험·의료급여)별 시계열을 선형 회귀로 외삽한 뒤 합산했습니다.
2023년까지 학습해 2024년을 예측한 백테스트 오차는 전체 0.27%, 65세 이상 0.32%(최근 추세 기준)입니다.
학습 기간이 5개 연도이고 인구 구조·제도 변화를 반영하지 않은 추세 외삽이므로 확정 예측이 아닌 시나리오 범위로 해석해야 합니다.

## 한계

- 혈압 스트림, 보호자·보건소 화면의 알림과 명단은 시연용 가상 데이터이며 실제 AI 모델이 아닙니다.
- HGI 계산기와 절감 효과 계산기는 가정값 입력 도구입니다. 실제 지역 지수나 절감액이 아닙니다.
- 시군구 탐색은 기관 수 기준이며 인구로 보정하지 않았습니다.
- 건보 데이터의 비공개(`*`) 16개 셀은 합계에서 제외했습니다.
- 경쟁 서비스 비교는 공개 보도와 일반 구조 요약이며 업로드 데이터 밖 자료입니다.
- 의료 진단 도구가 아닙니다.
